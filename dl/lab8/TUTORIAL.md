## Якщо скінчилась квота

Colab скаже щось на кшталт *«You cannot currently connect to a GPU due to usage
limits»*. Варіанти, від кращого до гіршого:

1. **Зачекати.** Ліміт поновлюється приблизно за добу. Уже виконані ноутбуки
   нікуди не діваються — результати лежать на Drive.
2. **Зменшити набір.** У клітинці **№2** поставити:
   ```python
   SUBSET = (2000, 500, 500)
   ```
   Епоха стає приблизно вп'ятеро коротшою, увесь ноутбук — хвилин 15. Точність
   просяде на один-два відсотки. **Це обов'язково зазначається у звіті**, і
   краще так для всіх чотирьох мереж, ніж для частини: інакше порівняння в
   пункті 5 буде нечесним.
3. **Прогнати на CPU в Colab.** Можливо для MobileNetV2, решта — надто довго.

| Симптом | Причина | Що робити |
|---|---|---|
| `GPU: НЕМАЄ` у клітинці №1 | не увімкнено GPU | Runtime → Change runtime type → T4, потім Restart session |

| `Drive mount failed` | підвисла сесія | Runtime → Disconnect and delete runtime, почати заново |
| сесія відвалилась посеред навчання | Colab відключив за неактивність | перезапустити з №1; клітинки №4 і №5 ідемпотентні й відпрацюють швидко |
