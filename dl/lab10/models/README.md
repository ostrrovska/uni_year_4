# Збережені моделі

Умова вимагає здати навчені нейромережі. Самі файли `.keras` сюди не
комітяться — найбільші з них важать понад 300 МБ, що не має сенсу тримати в
репозиторії. Ноутбуки зберігають їх у **`MyDrive/dl_lab10/models/`**, а тут
лежить опис: що це за модель, звідки вона й чим відрізняється.

## Звідки беруться файли

Кожен ноутбук наприкінці зберігає свої моделі й копіює їх на Drive сам.
Окремо нічого завантажувати не треба.

| Файл | Ноутбук | Що це |
|---|---|---|
| `task2_base_150.keras` | Завдання 2 | InceptionV3 до `mixed7`, вхід 150×150, без аугментації |
| `task2_aug_150.keras` | Завдання 2 | те саме з аугментацією |
| `task2_base_300.keras` | Завдання 2 | вхід 300×300, 227 млн параметрів |
| `task2_aug_ft_150.keras` | Завдання 2 | аугментація + донавчання з `mixed6` |
| `task3_vgg16_*.keras` | Завдання 3 | VGG16 на скороченому наборі коти-собаки |
| `task3_inception_*.keras` | Завдання 3 | InceptionV3, те саме |
| `task3_resnet50_*.keras` | Завдання 3 | ResNet50, те саме |
| `task3_best_*.keras` | Завдання 3 | найкраща конфігурація за точністю на тесті |
| `task4_rps.keras` | Завдання 4 | власна CNN на три класи, Rock-Paper-Scissors |

Завдання 3 зберігає не всі вісім експериментів, а найкращий загалом і
найкращий для кожної з трьох основ — решта відрізняється лише
гіперпараметрами, і їхні числа повністю є у `results/raw/task3.json`.

## Як завантажити модель назад

```python
import tensorflow as tf

model = tf.keras.models.load_model('/content/drive/MyDrive/dl_lab10/models/task4_rps.keras')
model.summary()
```

Формат `.keras` зберігає архітектуру, ваги й стан оптимізатора разом, тож
модель можна одразу використовувати для прогнозів або донавчати далі.

**Важливо про препроцесію.** Моделі Завдання 3 чекають на вході не звичайне
`rescale=1./255`, а препроцесію своєї основи: VGG16 віднімає середнє ImageNet
по каналах, InceptionV3 масштабує пікселі в `[-1, 1]`. Якщо підставити не ту
нормалізацію, модель мовчки почне помилятися, без жодного винятку в коді. Яка
саме потрібна — записано в `results/raw/task3.json` у полі `base` кожного
експерименту.

Моделі Завдання 2 і 4 навчені на `rescale=1./255`.

## Якщо виводи ноутбуків загубилися

Усі числа дублюються у `results/raw/*.json`, а самі моделі — на Drive. Тобто
навіть без збережених виводів кодових комірок результати відновлюються:
`scripts/collect_results.py` збирає з JSON-ів таблиці для звіту.
