Самі файли `.keras` лежать на Google Drive у `MyDrive/dl_final_project/models/`,
а не в репозиторії: кожна модель важить від кількох до сотень мегабайтів.

Ноутбуки зберігають **кожен** експеримент — під іменем прогону, тобто
`<ім'я експерименту>.keras`. Поряд, у `MyDrive/dl_final_project/runs/`, лежить
JSON із числами того ж прогону, тож до будь-якої моделі завжди відомо, звідки

| Що | Де |
|---|---|
| моделі з нуля | `models/a*.keras` |
| перенесення навчання й донавчання | `models/b*.keras` |

| проміжні чекпоінти під час навчання | `/content/ckpt/` у Colab — на Drive не копіюються |

## Як завантажити модель

Усе потрібне вбудоване в саму модель: нормалізація входу — шаром `Rescaling`,
аугментація — шарами `Random*`, які автоматично вимикаються поза навчанням.
Тому сторонніх об'єктів при завантаженні не потрібно:

```python
from tensorflow import keras

model = keras.models.load_model('/content/drive/MyDrive/dl_final_project/models/<ім'я>.keras')
```

Виняток — `c4_focal` із ноутбука 05: він навчений власною функцією втрат,
тому завантажувати його треба з `compile=False` (для прогнозів компіляція не
потрібна, а відтворювати функцію втрат заради `predict` немає сенсу).

Подавати на вхід треба масив `float32` у діапазоні **0–255** розміру
`(N, img_size, img_size, 3)`, де `img_size` записаний у полі `config.img_size`
відповідного JSON-а з `runs/` (за замовчуванням 224). Приклад — у розділі 9
ноутбука [04_evaluation.ipynb](../notebooks/04_evaluation.ipynb).
